## Full Summary

This evaluation loads the real EXPERIMENT artifact output (gen_art_experiment_1/method_out.json: 3 models x 3 benchmarks x 10 problems x 5 repeated samples = 90 problems, 450 raw samples) and tests whether the Taylor power-law exponent b predicts self-consistency voting gain. Because the EXPERIMENT only fits b at the (model, benchmark) granularity (9 combos, 3 with a degenerate/null fit from too few valid problems in this budget-scaled run), two complementary analyses are reported: (1) combo_level_spearman -- the literal plan-specified test of fitted b vs. aggregate voting gain across the 5 valid (model, benchmark) combos (rho=-0.90, p=0.037, but n=5 is severely underpowered, flagged explicitly); (2) a per-problem analysis using od_p = v_p_empirical/(m_p(1-m_p)), the real per-problem overdispersion ratio (the finest-grained analog of b available, since true per-problem b is undefined), against real per-problem voting gains recomputed from raw correctness_samples via majority vote. On this n=90 basis the evaluation implements the full artifact plan: within-benchmark Spearman rho with 10k-iteration bootstrap CIs at k=5 (and secondary k=3,10), a 60/40 stratified calibration/holdout linear-regression transfer test with attenuation factor, cross-benchmark transfer (train on GSM8K, test on MMLU/ARC-Challenge), difficulty-stratified (low/medium/high m_p tercile) correlations with Holm-Bonferroni FWER correction, a noise-floor gate using the EXPERIMENT's own per-combo null-simulation p-values, DerSimonian-Laird random-effects meta-analytic pooling of all rho estimates with tau^2/I^2/Q heterogeneity, Cohen's d effect sizes (top vs bottom od_p quartile), and scatter/histogram visualizations with regression bands by benchmark and stratum. Key real finding: 0 of 5 testable (model, benchmark) combos rejected the i.i.d.-Bernoulli null at p<0.05 (min p=0.181) -- per the plan's own stated logic, this means the exponent-based diagnostic is not established as distinguishable from sampling noise at this experiment's scale, so all downstream correlation estimates (within-benchmark rho ~0.16-0.28, pooled meta-analytic rho=0.21 with near-zero heterogeneity) should be read as directional/exploratory rather than confirmatory. All code paths are fully general (no hard-coded results) and will produce statistically meaningful, adequately-powered output if the EXPERIMENT is rerun at a larger N.
